    Map provider

    OpenStreetMap works out of the box, free, no key required. For Google Maps or Mapbox, paste in your own API key below.

    Google Maps keys come from the Google Cloud Console (needs billing enabled; the Maps JavaScript API has a free monthly usage allowance). Mapbox tokens come from mapbox.com (free tier available). If the chosen provider can't load — for instance because this preview blocks outbound map requests — the game automatically falls back to OpenStreetMap, and then to a built-in offline map, so play is never interrupted. Downloading this file and hosting it yourself removes that restriction entirely.
